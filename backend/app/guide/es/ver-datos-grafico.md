# Ver los datos de un gráfico

## Para qué sirve

Leer las cifras exactas que hay detrás de una tarjeta —una barra, una porción, una tendencia o un
indicador— sin pasar el ratón marca por marca ni descargar el CSV.

## Quién puede usarlo

Cualquier persona que pueda ver el reporte. La tabla muestra los mismos datos que ya dibuja la
tarjeta; no abre permisos nuevos.

## Cómo se hace

1. Abre un reporte y busca la tarjeta que te interesa.
2. Pulsa **Ver como tabla** en el menú **⋯** o el icono de tabla junto a **Ampliar**. También puedes
   hacer doble clic en la tarjeta o pulsar `T` con la tarjeta enfocada.
3. La tabla muestra las filas que dibuja el gráfico, con sus mismas etiquetas y formatos.
4. Busca un valor, pulsa una cabecera para ordenar, **Copiar** para llevarte la tabla o **Descargar
   CSV** para guardarla.
5. Con la tarjeta ampliada, el selector **Gráfico | Tabla** cambia entre el dibujo y los datos.

## Opciones

- `?tabla=<id de la tarjeta>` abre la tabla directamente y se puede compartir.
- **Ver todas las filas** aparece cuando el ranking o la tabla estaban cortados; pide el resto hasta
  1.000 filas, en páginas de 50.
- Pulsar una fila de un ranking o de una tabla filtra el tablero igual que pulsar la marca.
- Un reporte o una tarjeta pueden ocultar estos accesos; si no ves el icono, el autor lo configuró
  así.

## Problemas frecuentes

- No aparece el icono de tabla: la tarjeta no tiene datos o el autor desactivó **Ver como tabla**.
- La tabla no muestra todas las filas: usa **Ver todas las filas** si la vista estaba cortada.
- El botón Copiar no responde: el navegador puede bloquear el portapapeles; el CSV sigue disponible.
