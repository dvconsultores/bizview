# Historial del proyecto

## Para qué sirve

Guarda cada cambio de cada archivo del proyecto: quién lo hizo (una persona, el agente con su
comando, una importación o un cambio externo) y permite volver atrás.

## Quién puede usarlo

Solo el **Superusuario**.

## Cómo se hace

1. En el editor del proyecto pulsa **Historial**.
2. Filtra con **Filtrar por archivo** o **Filtrar por spec**.
3. Cada cambio muestra el autor, el comando (por ejemplo `/speckit-plan`) y la conversación.
4. Para ver diferencias, elige dos versiones con **Desde** y **Hasta** y pulsa **Comparar**.
5. Para volver a una versión, pulsa **Restaurar**: se crea un cambio nuevo, nada se borra.

## Opciones

- La **Línea de tiempo** de una spec muestra su paso por las etapas y los comandos que la
  cambiaron.
- **Cambio externo**: el archivo cambió en el disco fuera de BizView.
- Las aplicaciones del proyecto también aparecen en el historial.
