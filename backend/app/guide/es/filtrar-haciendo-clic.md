# Filtrar haciendo clic

## Para qué sirve

Leer un tablero pulsando lo que te interesa: una barra, una porción, una fila de un ranking o una
celda de una tabla. Todo el tablero —indicadores incluidos— se recalcula con ese valor.

## Quién puede usarlo

Cualquier persona que pueda ver el reporte. El clic no cambia permisos: solo filtra los datos que ya
puedes ver.

## Cómo se hace

1. Abre un reporte y pulsa un valor: una barra, una porción del pastel, una fila del ranking o una
   celda de una columna de dimensión.
2. El tablero se filtra. La tarjeta donde pulsaste conserva todos sus valores y resalta el elegido;
   las demás muestran solo lo filtrado.
3. Pulsa el mismo valor otra vez para quitar el filtro.
4. Pulsa otro valor de otra dimensión y el filtro anterior se reemplaza. Mantén Ctrl (o Cmd en Mac)
   para conservarlo: suma valores de la misma dimensión o combina dimensiones distintas (AND).
5. Los filtros aparecen como chips bajo la línea del período. **Limpiar** los quita todos.

## Opciones

- Los valores se guardan en la URL, así que puedes compartir el enlace, recargar la página o
  exportar el PDF/CSV con el mismo filtro.
- «Otros», los totales y los puntos de la tendencia no se pulsan.
- En la hoja **Filtros** ves los mismos valores cuando la dimensión está listada allí.
- Un tablero puede desactivar el clic: si un valor no responde, el autor lo configuró sin
  interacción.

## Problemas frecuentes

- No aparece el chip: el filtro se aplicó desde la hoja, no desde un clic; revisa la hoja Filtros.
- El valor no responde: ese componente puede estar marcado como no interactivo, o el valor es
  «Otros»/un total.
- El tablero muestra el total aunque hayas pulsado en otra tarjeta: ese indicador está configurado
  para ignorar los filtros de clic.
