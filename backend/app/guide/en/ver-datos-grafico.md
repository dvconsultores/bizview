# See a chart's data

## What it is for

Read the exact figures behind a card — a bar, a slice, a trend or a KPI — without hovering mark by
mark or downloading the CSV.

## Who can use it

Anyone who can see the report. The table shows the same data the card already draws; it grants no
new permissions.

## How to

1. Open a report and find the card you want.
2. Press **View as table** in the **⋯** menu or the table icon beside **Enlarge**. You can also
   double-click the card or press `T` while the card is focused.
3. The table shows the rows the chart draws, with the same labels and formats.
4. Search for a value, press a header to sort, use **Copy** to take the table or **Download CSV** to
   save it.
5. In a maximized card the **Chart | Table** switch moves between the drawing and the data.

## Options

- `?tabla=<card id>` opens the table directly and can be shared.
- **View all rows** appears when the ranking or table was cut; it asks for the rest up to 1,000 rows,
  in pages of 50.
- Pressing a ranking or table row filters the dashboard just like pressing the mark.
- A report or a card can hide these entry points; if the icon is missing, the author turned it off.

## Common problems

- The table icon is missing: the card has no data or the author disabled **View as table**.
- The table does not show every row: use **View all rows** when the view was cut.
- Copy does nothing: the browser may block the clipboard; the CSV still works.
