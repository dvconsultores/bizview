# Dashboards

## What it is for

It lists every dashboard you can access, to search and open them.

## Who can use it

Anyone with an account. Each person sees only the dashboards assigned to them.

## How to

1. Open [Open Dashboards](app:/tableros).
2. Type in **Search dashboard** to filter by name.
3. Switch between **Card view** and **Table view**.
4. Tap a dashboard to open it; the star adds it to **Favorites**.

## Options

- A dashboard marked **Coming soon** has no published data yet.
- A direct link to a dashboard (`/d/…`) opens that dashboard if you have access.

## Common problems

- **Not authorized**: the dashboard exists but you have no access; ask your administrator.
- **Dashboard not found**: the link is wrong or the dashboard no longer exists.
