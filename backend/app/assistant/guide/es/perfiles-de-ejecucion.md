# Perfiles de ejecución

## Para qué sirve

Un perfil guarda un contrato de run —hasta dónde puede llegar el asistente en modo Auto, con qué
fuentes y con qué límites— para repetir un run rutinario sin volver a escribirlo.

## Quién puede usarlo

Solo el superusuario, como todo el Asistente.

## Cómo se hace

1. Abre Administración → IA → Perfiles de ejecución.
2. Escribe el nombre del perfil y los límites: aplicaciones por run, vistas previas y minutos.
3. Pulsa «Nuevo perfil».
4. En una conversación, pon el modo en «Auto»: el contrato ofrece el perfil y rellena los campos.
5. Confirma el contrato con tu contraseña (y el código de dos pasos si la instalación es
   `internet`).

## Opciones

- Un perfil no autoriza nada: cada run sigue pidiendo tu confirmación con contraseña.
- El objetivo del run siempre es tu petición; el perfil no lo guarda.
- Al eliminar un perfil queda registrado en la auditoría.
- Para entender el modo Auto y sus límites, consulta [El chat del asistente](app:/admin/ia).
