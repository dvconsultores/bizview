# Tableros

## Para qué sirve

Lista todos los tableros a los que tienes acceso para buscarlos y abrirlos.

## Quién puede usarlo

Cualquier persona con una cuenta. Cada uno ve solo los tableros que le asignaron.

## Cómo se hace

1. Abre [Abrir Tableros](app:/tableros).
2. Escribe en **Buscar tablero** para filtrar por nombre.
3. Cambia entre **Vista de tarjetas** y **Vista de tabla**.
4. Toca un tablero para abrirlo; la estrella lo agrega a **Favoritos**.

## Opciones

- Un tablero marcado **Próximamente** aún no tiene datos publicados.
- Un enlace directo a un tablero (`/d/…`) abre ese tablero si tienes acceso.

## Problemas frecuentes

- **No autorizado**: el tablero existe pero no tienes acceso; pídelo a tu administrador.
- **Tablero no encontrado**: el enlace es incorrecto o el tablero ya no existe.
