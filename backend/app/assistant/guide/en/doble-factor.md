# Two-step verification

## What it is for

It asks for a code from your phone besides the password, so nobody gets into your account with
the password alone.

## Who can use it

Anyone with an account. In installations with the internet profile it is required for
administrators and the **Superuser**.

## How to

1. Open [Open two-step verification](app:/seguridad/doble-factor) (also from the
   **Two-step verification** card of your profile).
2. In **Set up two-step verification**, scan the QR code with an authenticator app. If you
   cannot scan, type the key shown.
3. Type the 6-digit code and press **Activate**.
4. Save the recovery codes with **Download .txt** and press **I've saved them**. Each code works
   only once and they are not shown again.

## Options

- **Generate new recovery codes**: the previous ones stop working.
- **Deactivate**: turns verification off (not available when it is required).
- If you lost the phone and the codes, ask an **Administrator** to use **Reset two-factor** in
  your user page. An **Administrator**'s two-factor is reset by the **Superuser**.

## Common problems

- "The code is invalid. Check your phone's time and try again.": codes depend on the time; turn
  on automatic time on the phone.
