# Share with a link

## What it is for

It creates a link that lets people view a dashboard without an account, for a limited time.

## Who can use it

An **Administrator** or the **Superuser** creates it, when the installation has shared links
turned on. Anyone with the link can open it while it is valid.

## How to

1. Open the dashboard and press **Share**.
2. In **Share dashboard** choose the **Validity (days)**, between 1 and 90 days.
3. Optional: type a **Note (optional)** to remember who you gave it to.
4. Press **Create link** and copy it: it will not be shown again.

## Options

- **Active links** lists the dashboard's links with their visits; **Revoke** cancels one at once.
- Each dashboard accepts up to 20 active links created by hand; links created by an email send or
  a scheduled send do not count toward the limit.
- Whoever opens the link sees **Shared view · expires on** … and can change the filters, but does
  not see the rest of the app.
- A project can limit or turn off the links of its reports (see Distributions).

## Common problems

- "This link expired or was revoked": ask for a new link.
- "Too many visits": the link got many visits in a row; try again in a few minutes.
