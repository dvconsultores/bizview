# Project editor

## What it is for

It is a project's workplace: its files, its validation problems and the agent's chat, like a code
editor in the cloud.

## Who can use it

Only the **Superuser**.

## How to

1. Open a project from [Open Projects](app:/proyectos).
2. In the **File explorer** open a file; it opens in a tab of **Open files** (up to 8 with unsaved
   changes).
3. .md files are shown as a document: **View code** shows the text and **View document** goes
   back. YAML, SQL and JSON are edited with colours.
4. Press **Save**. Validation runs on save and the status bar says **Valid**, how many problems
   there are, or **Ready to apply**.
5. In **Problems** tap a problem to go to the file and line.

## Options

- **New file**, **New folder**, **Rename** and **Delete** work only inside the project's allowed
  paths (see Project structure). With the keyboard, in the explorer press F2 to rename and Delete
  to delete the selected item.
- The chat panel works with the **Current spec** you choose; **New chat in this project** opens
  another conversation.
- On a phone, the **Files**, **Editor** and **Chat** tabs show one panel at a time.
- While the agent works you see "The assistant is editing the project…" and files update by
  themselves.

## Common problems

- If someone changed a file while you were editing it, the editor lets you reload, overwrite or
  discard your changes.
