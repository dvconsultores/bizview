# Send by email

## What it is for

It emails a dashboard with its PDF and, if you want, a link to view it online.

## Who can use it

Anyone with access to the dashboard, when the installation has email set up.
**Include link** is for administrators only.

## How to

1. Open the dashboard and press **Send by email**.
2. In **Recipients** search users or type an **External email** (only from the domains the
   installation allows) and press **Add**.
3. Type the **Subject** (if left empty, the dashboard name is used) and a
   **Message (optional)**.
4. Tick **Attach PDF of the current period and filters**.
5. Administrators: tick **Include link** and choose the **Link validity (days)**.
6. Press **Send**.

## Options

- **Sends** shows each send's status: **Queued**, **Sending**, **Sent**, **Partially sent** or
  **Failed**.
- Limits: up to 20 recipients per send and 30 sends per hour; the PDF cannot exceed 10 MB.

## Common problems

- "Email sending is not available in this installation.": the **Superuser** must set up email.
