# Tasks: Spec Kit commands in the chat and BI-only scope

**Roles**: Claude thinks (spec, plan, tasks, briefs) and audits/converges; DeepSeek executes (writes
all code, prompts, tests and fixes). Security-sensitive (server-side tool and path guards, scope gate,
untrusted-data delimiting, migration): Claude reviews line by line. No live AI in tests (fake provider,
inline runner); the scope eval runs only with `AI_LIVE_TESTS=1`. Code first, test last: each task has
focused checks only; full suites run once at the end of the queue.

**Depends on**: 022 (catalogues, request locale, `app_user.locale`) and 020 (`backend/app/projects/`,
`project_file_revision`, `assistant_session.project_id` / `current_spec`, 017 tools on the project
folder). Every new UI string goes into `frontend/src/i18n/es.ts` and `en.ts`; every backend message
into `backend/app/i18n/es.py` and `en.py`.
