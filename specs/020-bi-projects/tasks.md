# Tasks: BI projects — a workspace per chat with numbered specs

**Input**: [spec.md](./spec.md), [plan.md](./plan.md), [research.md](./research.md)

**Roles**: Claude thinks (spec, plan, tasks, briefs) and audits/converges; DeepSeek executes (writes
all code, tests and fixes). Security-sensitive (path resolution, zip import, migration, step-up
routes, AI data boundary of project files): Claude reviews line by line. No live AI in tests (fake
provider). No modal dialogs: every confirmation is an inline bar or a view. Every new UI string goes
into `frontend/src/i18n/es.ts` **and** `frontend/src/i18n/en.ts`; every backend message through
`backend/app/i18n/{es,en}.py` (022). Backend tests run on `DATABASE_URL_BI` in `app_test_*` schemas
with `PROJECTS_DIR` set to a pytest `tmp_path`. Code first, test last: each task ends with its
focused check only; full suites run once at the end of the queue.

**Format**: `- [ ] T0NN [P?] [USn] description — paths — per FR-…`. `[P]` = different files, no
dependency on an unfinished task.

**Prerequisites**: 019 (migration 0015), 005-A (0016, if created), 022 (0017_user_locale, i18n
catalogues and `useT()`) are implemented; `0018_projects` revises `0017_user_locale`.
