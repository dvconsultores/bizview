# Data model — starter pack

## StarterPack

The folder `pack/bizview-starter-pack/`. Not user data: it ships with the product.

| Field | Meaning |
|---|---|
| `es/`, `en/` | the documents written for a reader, one folder per language |
| `files/` | the skeletons copied verbatim, with `{{placeholders}}` |
| placeholders | `{{name}}`, `{{slug}}`, `{{date}}`, `{{source}}`, `{{table}}` |

## RenderedPack

What `bizview_cli.starter.render()` answers: `dict[path, bytes]` with the selections applied.

| Input | Values | Effect |
|---|---|---|
| `name` | 1–80 chars | `project.yaml:name`, `bizview.yaml:name`, prose |
| `slug` | `[a-z][a-z0-9-]{1,49}` | `project.yaml:slug`, every `NNN-<slug>` and artifact id |
| `lang` | `es` / `en` | primary documents; the other language carries the suffix |
| `kind` | `integration` / `direct` | presence of `integrations/<slug>/` and the report's `datasets` or `direct` |
| `source` | a registered source name | adds `sources/<name>/structure.{md,json}` |
| `template` | bool | keeps `<slug>`, `<nombre>` and the generic prose; no source |

Invariants:

1. Sorted entry names, no directory entries, fixed timestamp → identical bytes for identical input.
2. Every zip carries `CONTENIDO.md`, `CONTENTS.md`, `QUE-HACE-BIZVIEW.md` and
   `WHAT-BIZVIEW-DOES.md`.
3. Every path inside `CONTENIDO.md`'s table exists in the zip, and every zip path is in the table.
4. The rendered project validates (zero errors) when written into `projects/<slug>/` of a workspace
   with a `bizview.yaml`.
5. `PROMPT.md` is under 1,500 words.

## StarterTemplate

`bizview-starter-template.zip` at the repository root: `render(template=True, lang="es")`. Committed,
regenerated by `make starter-template`, attached to a release (046), served by
`GET /api/projects/starter-template`.

## StructureDocument

`sources/<name>/structure.md` + `structure.json`, rendered by the generator of 048/052.

| Field | Comes from |
|---|---|
| tables, columns, types, nullability | `sources.describe` |
| row counts, date ranges, personal flags | the same describe plus the saved flags |
| samples, shapes, pagination hints | the source's saved sample requests |

Never: credentials, host, connection string, row values.

## ContentsDocument

`CONTENIDO.md` / `CONTENTS.md`: one row per file of the zip with four columns — file, required,
written by, what Bizview does with it — plus the naming rules, what import ignores and the budgets.

## ImportWalkthrough

`QUE-HACE-BIZVIEW.md` / `WHAT-BIZVIEW-DOES.md`, and the same text as the guide topic
`importar-y-aplicar` (rendered from the pack at build time by the test that compares them).
