# Data Model: Data Sources and Internet-Grade Security

**Feature**: [spec.md](./spec.md) | **Plan**: [plan.md](./plan.md) | **Date**: 2026-09-29

Migration `0003_sources_security` (schema `public`, like features 002–003). Encryption format:
`nonce(12) || AES-256-GCM(ciphertext + tag)`, key id = first 8 hex chars of SHA-256(key) — see
[research R1](./research.md).

## data_source — *Data Source*

| Field | Type | Rules |
|---|---|---|
| id | bigint PK identity | |
| name | text | required, unique (case-insensitive: unique index on `lower(name)`), 1–80 chars |
| kind | text | `postgresql` \| `soap` \| `rest` (this version; SQL Server later) |
| description | text | ≤ 300 chars, default `''` |
| enabled | boolean | default true |
| settings | jsonb | non-secret settings, validated per kind ([contracts/connectors.md](./contracts/connectors.md)) |
| secrets_ct | bytea null | encrypted JSON of secret fields; AAD `bizview:v1:data_source:<id>:secrets` |
| secrets_key_id | text null | key id used; required when `secrets_ct` is set |
| secret_fields | text[] | names of configured secret fields (no values), default `{}` |
| imported | boolean | default false; true for the legacy `DATABASE_URL_ORIGIN` import (notice shown until edited) |
| last_test_at | timestamptz null | |
| last_test_ok | boolean null | |
| last_test | jsonb null | `{code, message, latency_ms, details}` — never secrets |
| created_at, updated_at | timestamptz | |
| created_by, updated_by | bigint FK → app_user null | |

Checks: `(secrets_ct IS NULL) = (secrets_key_id IS NULL)`; kind in the list.
State: `enabled` ⇄ `disabled`. Deletion is refused while a dashboard dataset references the
source (feature 001 adds that reference; until then deletion is allowed after confirmation).

## security_state (singleton)

| Field | Type | Rules |
|---|---|---|
| id | smallint PK | CHECK `id = 1` |
| key_id | text | id of the key currently used |
| key_check | bytea | encryption of a fixed marker; AAD `bizview:v1:security_state:key_check` |
| key_rotated_at | timestamptz null | |
| legacy_origin_notice | boolean | default false; true after importing `DATABASE_URL_ORIGIN` |

Created on the first encryption; verified at every start when present.

## recovery_code

| Field | Type | Rules |
|---|---|---|
| id | bigint PK | |
| user_id | bigint FK → app_user | ON DELETE CASCADE |
| code_hash | text | Argon2id of the normalised code (upper-case, no dash) |
| used_at | timestamptz null | single use |

Regenerating replaces all of a user's codes. Disabling two-step sign-in deletes them.

## user_session (added columns)

| Field | Type | Rules |
|---|---|---|
| mfa_pending | boolean | default false; true between password and second factor; such a session expires 5 min after `created_at` and allows only the second-factor and logout endpoints |
| reauth_at | timestamptz null | last password confirmation (step-up valid 5 min) |

## login_throttle

| Field | Type | Rules |
|---|---|---|
| ip | inet | PK part |
| window_start | timestamptz | PK part; start of the fixed window |
| failures | int | ≥ 0 |
| limited_audited | boolean | default false (one audit event per window) |

Rows older than 1 day are purged.

## audit_event.kind (extended)

Adds: `source_created`, `source_updated`, `source_deleted`, `source_tested`, `source_enabled`,
`source_disabled`, `source_imported`, `mfa_enabled`, `mfa_disabled`, `mfa_reset`,
`recovery_code_used`, `recovery_codes_regenerated`, `reauth_ok`, `reauth_failed`,
`login_rate_limited`, `admin_address_refused`, `secret_key_rotated`. Details never contain secret
values; source updates record the changed setting names and which secret fields changed.
