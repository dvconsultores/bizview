# Contract: `layout.pdf` document

**Owner**: `cli/bizview_cli/schemas/report.schema.json` (`$defs.pdf_layout`). Consumers:
`bizview validate`, the Asistente authoring guide, `backend/app/reports/pdf_layout.py`.

## Shape

```yaml
# reports/ventas/report.yaml (excerpt)
layout:
  pdf:
    page:
      size: a4            # a4 | letter
      orientation: portrait
      margins: { top: 12, right: 10, bottom: 12, left: 10 }   # millimetres, integers 5–40
    overflow: continue    # continue | truncate
    blocks:
      - id: cabecera
        type: header
        title: true
        subtitle: true
        period: true
        logo: true
        logo_role: brand
      - id: mes
        type: kpi_row
        view: resumen
        items: [ventas_netas, ticket_medio]
        delta: true
      - id: diaria
        type: chart
        view: diaria
        kind: line
        x: fecha
        series: [ventas_netas]
        height_mm: 60
      - id: producto
        type: table
        view: producto
        columns: [producto, ventas_netas]
        widths: [3, 1]
        totals: true
        overflow: truncate
      - id: pie
        type: footer
        generated_at: true
        page_numbers: true
        legal: "Documento generado por el cliente."
        legal_en: "Document generated by the customer."
```

## Rules the validator enforces

| # | Rule | Severity |
|---|---|---|
| 1 | Every `view` equals the `id` of a declared view of the same report (a view declares its own optional `id`); every `items`/`series`/`columns` id exists in the report. Binding is by id — never by array index or by view `type`. | error |
| 2 | `type` is in the catalogue: `header`, `kpi_row`, `chart`, `table`, `text`, `page_break`, `footer`. | error |
| 3 | `id` values are unique inside `blocks`; `blocks` is not empty. | error |
| 4 | `page.size` and `page.orientation` are one of the named values; margins are integers 5–40. | error |
| 5 | `widths` has exactly as many entries as `columns`; `height_mm` is 30–200. | error |
| 6 | `logo_role` is `brand` or `none` — never a path or a URL (VII). | error |
| 7 | A `footer` or `page_break` appears at most once as the last block. | warning |
| 8 | `layout.pdf` together with the legacy `pdf.views`/`pdf.orientation`. | warning (`pdf.*` is ignored for order/orientation) |

## Rendering contract (backend)

- **Entry**: `backend/app/reports/pdf.py::render(definition, payload, *, organization, product,
  viewer, preview, layout, locale)`. When `definition["layout"]["pdf"]` is present,
  `PdfLayoutRenderer` produces the story; otherwise the current fixed story runs unchanged (FR-009).
- **Page**: `page.size`/`page.orientation`/`margins` build the `SimpleDocTemplate`; the defaults are
  today's A4 portrait with 10 mm sides and 12 mm top/bottom.
- **Branding**: `organization`, `product` and the logo come from the installation configuration that
  `render()` already receives; the layout only says *whether* to show them (VII).
- **Charts**: vector drawings from `reportlab.graphics` (`LinePlot` as today; `VerticalBarChart`,
  `HorizontalLineChart`, `Pie` for the other kinds). The engine's `views[].summary` becomes the chart
  caption, so the same words describe the figure on screen and on paper.
- **Tables**: `Table` with `repeatRows=1`; `overflow: continue` lets ReportLab paginate the table with
  its header, `overflow: truncate` stops at the page boundary and prints the localised "y N más" line
  with the number of rows left out. `totals` prints the engine's `views[].totals` as a final row,
  outside the repeat region.
- **Text**: the same markdown subset as the web, as `Paragraph`s with the named font family.
- **Localisation**: `text`/`text_en`, `legal`/`legal_en` and every renderer string resolve through the
  backend catalogue in the request's locale (already `use_locale(...)` inside `render`).
- **Output**: `application/pdf` only, unchanged routes
  (`POST /api/reports/{report_id}/pdf`, `POST /api/projects/{slug}/preview/report/{report_id}/pdf`).
- **Budget**: a 4-block report with a 500-row table renders under 10 s; a layout that fits one page
  stays one page (`pageCompression=0` and `invariant=1` stay for the tests).
